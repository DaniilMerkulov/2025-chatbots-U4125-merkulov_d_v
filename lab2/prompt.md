# Финальный промпт

Промпт, по которому сделано подключение к API Wildberries. Это исходный промпт с учетом двух уточнений: про работу в отдельном потоке и про понятные сообщения об ошибках.

```
Замени тестовые данные в моем Telegram-боте на настоящий API Wildberries.

Сейчас модуль wb_api.py возвращает выдуманные цифры. Нужно, чтобы он
брал их из кабинета продавца по API-ключу пользователя.

Что нужно получать за указанный день:
- заказы: сумма в рублях и количество, без отмененных
- выкупы: сумма в рублях и количество, возвраты вычитать
- затраты на рекламу
- переходы в карточку товара и добавления в корзину

Конверсии считай сам из счетчиков, а не бери готовые проценты из ответа:
API отдает их по каждой карточке отдельно, а складывать проценты нельзя.
Нужны три: переход в корзину, корзина в заказ, переход в заказ.
ДРР считай как затраты на рекламу, деленные на сумму заказов.

Требования:
- формат словаря, который возвращает get_daily_stats, менять нельзя,
  остальной код бота должен остаться без изменений
- вчерашний день считать по московскому времени, а не по времени сервера
- запросы к Wildberries выполнять в отдельном потоке, чтобы бот
  не переставал отвечать другим пользователям, пока собирает данные
- сразу после нажатия кнопки отправлять сообщение, что данные собираются
- отдельный тип ошибки для проблем с Wildberries. Текст писать сразу
  для пользователя: если ключ не принят, объяснить, что он мог истечь
  или что при создании не отмечены нужные категории. Если превышен лимит,
  сказать подождать минуту. Коды ответов писать только в лог
- учесть лимиты на частоту запросов, при отказе по лимиту ждать столько,
  сколько указано в заголовке ответа, и повторять не больше трех раз
- комментарии в коде на русском

Сначала уточни по документации dev.wildberries.ru, какие методы актуальны
сейчас, какие у них адреса, параметры и имена полей в ответе.
Не бери это из памяти, методы могли измениться.
```
