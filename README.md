## О проекте

Бот присылает продавцу Wildberries сводку по магазину за предыдущий день: заказы, выкупы, затраты на рекламу, ДРР и три конверсии. Рассылка идет утром по московскому времени, отчет можно запросить и вручную.

Бот в Telegram: [@itmoftmi_mdv_bot](https://t.me/itmoftmi_mdv_bot)

Актуальный код бота лежит в [lab2/bot](lab2/bot), инструкция по запуску в [lab2/bot/README.md](lab2/bot/README.md). В папке [lab1/bot](lab1/bot) сохранена версия на тестовых данных, какой она была после первой лабораторной.

## Замечания по работе

Код написан не руками, а сгенерирован по промпту. Самое интересное наблюдение получилось такое: сгенерированный код запускался без единой ошибки, но одну из метрик считал неверно по смыслу. Заметить это удалось только потому, что предметная область знакомая. Подробности в разделе «Трудности и решения» отчета.

Токен бота и API-ключи пользователей в репозиторий не попадают: токен лежит в файле `.env`, ключи в локальной базе, оба исключены через `.gitignore`.
