# WB Daily Report Bot

Телеграм-бот для продавцов Wildberries. Каждое утро присылает сводку по магазину за предыдущий день. Отчет можно также запросить вручную в любой момент.

## Какие показатели в отчете

- Заказы в рублях и в штуках
- Выкупы в рублях и в штуках
- Затраты на рекламу
- ДРР (доля рекламных расходов)
- Конверсия из перехода в корзину
- Конверсия из корзины в заказ
- Конверсия из перехода в заказ

Все данные за предыдущий день, время московское.

## Как работает

Каждый пользователь загружает свой API-ключ из личного кабинета продавца Wildberries. Бот хранит ключ в своей базе и по нему тянет данные именно этого магазина. Ключи разных пользователей не пересекаются.

Утренняя рассылка настраивается индивидуально: можно выбрать время или вообще отключить уведомления и запрашивать отчет вручную.

На текущем этапе модуль `wb_api.py` возвращает тестовые данные. Это сделано специально: сначала отлаживается логика бота, а подключение настоящего API Wildberries делается отдельным шагом, и менять нужно будет только одну функцию внутри `wb_api.py`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | запуск бота и главное меню |
| `/report` | отчет за предыдущий день прямо сейчас |
| `/setkey` | добавить или заменить API-ключ Wildberries |
| `/settings` | время рассылки и включение/отключение уведомлений |
| `/help` | краткая справка |

## Установка и запуск

### 1. Нужен Python 3.10 или новее

Проверить версию:

```bash
python3 --version
```

### 2. Скачать проект и зайти в папку

```bash
cd wb-bot
```

### 3. Создать виртуальное окружение

Виртуальное окружение это отдельная папка со своим Python и библиотеками, чтобы пакеты проекта не смешивались с системными.

```bash
python3 -m venv venv
source venv/bin/activate
```

На Windows вместо последней строки:

```bash
venv\Scripts\activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Получить токен бота

1. Открыть в Telegram бота [@BotFather](https://t.me/BotFather)
2. Отправить команду `/newbot`
3. Указать имя бота и его адрес, который должен заканчиваться на `bot`
4. BotFather пришлет токен, это длинная строка вида `1234567890:AAAA...`

### 6. Создать файл .env

```bash
cp .env.example .env
```

Открыть `.env` и вставить свой токен вместо примера:

```
BOT_TOKEN=сюда_вставить_токен_от_BotFather
```

Файл `.env` добавлен в `.gitignore`, поэтому токен не попадет на GitHub.

### 7. Запустить бота

```bash
python bot.py
```

В терминале появится сообщение о том, что бот запущен. Терминал при этом закрывать нельзя: пока он работает, работает и бот. Остановить можно сочетанием Ctrl+C.

### 8. Проверить в Telegram

1. Найти своего бота по имени и нажать Start
2. Нажать кнопку «Добавить API-ключ» и отправить ключ из кабинета Wildberries
3. Нажать «Отчет за вчера» и проверить, что сводка пришла
4. В разделе «Настройки» выбрать время утренней рассылки

## Где взять API-ключ Wildberries

1. Зайти в личный кабинет продавца на seller.wildberries.ru
2. Нажать на название магазина в правом верхнем углу
3. Выбрать раздел «Настройки» → «Доступ к API»
4. Создать новый токен и отметить категории «Статистика», «Аналитика», «Продвижение»
5. Скопировать выданный ключ и отправить его боту командой `/setkey`

Ключ выдается один раз, поэтому его стоит сразу сохранить в надежном месте.

## База данных

Бот хранит данные в файле `bot_database.db` (SQLite). Таблица `users`:

| Поле | Что хранит |
|---|---|
| `telegram_id` | идентификатор пользователя в Telegram |
| `api_key` | API-ключ Wildberries |
| `notify_time` | время утренней рассылки, например `09:00` |
| `notify_enabled` | включены уведомления или нет |

Файл базы тоже добавлен в `.gitignore`.

## Безопасность

- Токен бота хранится только в файле `.env` и в коде не прописан
- API-ключи пользователей лежат в базе и не попадают в логи
- В интерфейсе бота ключ показывается не полностью, а только последними четырьмя символами
